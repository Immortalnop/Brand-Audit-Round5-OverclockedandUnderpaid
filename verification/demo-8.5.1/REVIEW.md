# Page override and supporting artifact layout, October 14, 2026

The URL skill accepts /brand-audit:audit URL with an optional --max-pages integer
from 1 to 100. The default remains 50. The bootstrap records the selected cap and
forwards the optional flag only to the existing acquisition command. Native
request/byte scaling is retained; acquisition/workflow/host time limits, AG checks,
merge and repair stages are unchanged. The 100-page ceiling is now shared from
constants rather than repeated in the wrapper. Invalid overrides fail before a
run directory is created. The entrypoint still exports the same public constant.

The run root contains the five main outputs: base-report.json, agent-outcomes.json,
final-report.json, final-report.md and repair-prompt.md. Supporting evidence,
AG notes, optional image/receipt and clock/context/bound instructions live under
verification/. Its generated README explains creation order and relationships.
The name describes supporting records, not proof that all findings are true.
The clock is the first saved file; core creates the base/packet, host saves six
outcomes, local merge creates final JSON, rendering creates Markdown and the local
repair exporter creates the complete handoff. All source/package/base/packet
preservation rules remain in force. Native-only/failure cases disclose missing
optional artifacts rather than listing files that were never created.

The canonical prompt, skill and embedded replay use consistent paths. The local
repair helper accepts the new nested layout and older flat runs. It rejects
ambiguous duplicate packet/record locations rather than silently mixing sources.
Image paths follow the same layout without claiming a view from a fetch receipt.
The terminal lists existing main/supporting files and ends with the same full
repair-file link and next prompt. No saved user archive is edited or migrated.
